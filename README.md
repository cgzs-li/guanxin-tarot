## 账号与数据

- 自选账号和密码。密码框遮挡输入，服务端仅存随机盐与 PBKDF2-SHA256 哈希，不存明文。
- HTTPS 会话 cookie：HttpOnly、Secure、SameSite=Lax，有效期 7 天；每账号最多保留 5 个会话。
- Durable Object 持久存储账号、会话摘要、一次免费使用记录、卡牌 ID、内容指纹、演示订单及短时演示会话。不保存问题、背景、追问原文。平台仍可能有独立访问记录。
- 注册/登录有 IP 摘要限流；演示订单和解读有账号日限额。暂不提供手机、邮箱验证或密码找回，请勿使用其他平台的密码。
- 免费阅读、订单确认和权益消耗有服务端幂等与并发保护。价格由服务端决定，客户端传价格或 paid 标记无效。

## 开发与部署

Node.js 22+：

```sh
npm ci
npm run build
npm test
npx wrangler dev
```

GitHub main 的 Cloudflare Workers Builds 构建并部署，配置见 wrangler.jsonc；绑定自有域名，Durable Object SQLite 迁移维持 v1。真实模型密钥如保留，只能存 Cloudflare Secret，不能提交公开仓库。

构建提取 78 牌/26 阵，public 仅含网页和静态资源。worker/generated-library.js 为生成文件、不提交。历史 llm-backend 是本机 Python AI 版，不是本轮公网账号后台。

`python tools/build_pages.py` 构建旧入口跳转页；`python tools/verify_live.py` 只读验收正式域名、套餐、AI 关闭状态及敏感路径，输出 live-verification.json，不建立账号或调用模型。

## 下一步接真实支付

需要可用支付商户、支付下单、服务端验签回调、金额/订单核验、重复回调保护、退款与权益回收、付费权益和模型预算联动。完成这些后再开放真实 AI；只把 GUANXIN_AI_ENABLED 改 true 不会解锁本版公开接口。演示订单不应直接转为真实已支付订单。

## 暂停网站

将 wrangler.jsonc 的 GUANXIN_SITE_ENABLED 改为字符串 false，提交并等待部署，可暂停整站；恢复则改回 true。删除 GitHub 仓库不保证独立 Cloudflare 服务停止。旧 Pages 入口可在仓库 Settings → Pages → Unpublish site 关闭。

模型访问可在供应商撤销网站专用密钥。不要随意删除 Durable Object 命名空间，那里保存账号及权益数据。
