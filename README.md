# 观心 · 内心观测室

塔罗自我探索网页试用版，包含78张去白边韦特牌图、25套牌阵、逐项背景填写及正逆位解读。

## 试用方式

通过 GitHub Pages 打开网页，或者完整下载网页与 `assets` 文件夹后打开 `index.html`。无需安装、登录或 API 密钥。

## 数据和体验边界

问题和背景只保留在当前页面，刷新或关闭后清除。本版本没有用户分析、反馈上传或后台存储；解读使用本地规则，不是 AI 实时分析，仅供娱乐和自我反思。

## 收集试用反馈

请试用者通过原分享渠道反馈：使用设备与浏览器、体验到哪一步、是否有卡顿或图片问题、追问是否贴合问题、解读哪里不清楚。截图请遮住不愿分享的问题内容。也可以在仓库 Issues 提交功能建议，请勿公开个人隐私。

## GitHub Pages

在仓库 Settings → Pages → Source 选择 GitHub Actions，然后运行 Deploy preview 工作流。工作流只发布网页、牌图和图片来源文件，不发布其他工作文件。

## 图片来源

传统 Rider–Waite–Smith 牌组，Pamela Colman Smith 绘制，Wikimedia Commons Geldard 分类。各文件元数据标记 Public domain；本项目缩放并裁除外圈白边。逐张来源见 `牌图来源.json`。
