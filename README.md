## 正式规则（2026-10-27）

78 张牌、26 套牌阵、正逆位抽牌。每个账号有一次免费本地完整解读，不含 AI；成功生成后扣次。刷新、退出或换设备登录同账号不会恢复。同一自然人仍可能注册多个账号，本版没有实名或短信识别。

免费用完后需要充值。付费套餐提供真实大模型解读和限定轮数追问，不能靠点击按钮或旧演示余额解锁。原演示购买接口已返回410，不再提供模拟交易。

AI 模式恢复问题润色及根据当前问题生成三个背景问题。有可用次卡或月卡当日权益时可用，作为解读前辅助，不额外扣解读次数；仍受模型限流影响。免费本地模式不调用这些接口。负责人会话可直接测试，退出即失效。润色先预览、由用户采用；三问生成失败或开始填写时保留本地问题及回答，牌阵继续由本地规则推荐或手动选择。

## 人工收款

1. 用户登录，在套餐页选择套餐并创建待付款订单。
2. 用户将订单号发给向其分享网站的负责人，双方核对收款对象、套餐及金额后线下付款。网站不自动扣款，也不提供自动支付回调。
3. 负责人到 https://tarot.ruichi0201.cn/assets/admin.html ，登录负责人后台账号后输入订单号，核对账号与套餐。
4. 在自己的收款工具中确认真实到账后，填写实收金额和交易流水编号，勾选核实并开通。
5. 用户点击“刷新到账状态”，使用已开通的AI解读次数。

管理员确认接口要求专用随机凭证；服务器只配置其SHA256验证值。原凭证不进入仓库、不放在URL或浏览器本地存储，不能发给用户。只知道哈希不能登录。金额由服务器套餐目录决定，同笔订单重复确认不加次数，同一流水摘要不能用于不同订单。请勿把订单号当作收款流水号。

退款目前由负责人线下核对处理，没有自动退款或权益撤回界面；请先核对未用权益再处理，不能把页面状态当银行到账事实。接自动收款仍需商户、验签回调、金额核验及退款/权益回收机制。

管理页提供固定虚构问题的真实AI连接检测，每小时最多3次；不产生用户订单或收款记录。人工确认测试只在隔离的本地数据库进行，不能伪造线上实收订单来验证。

## 数据与保护

密码8～72字符、PBKDF2-SHA256随机盐哈希；密码框遮挡。会话cookie为HttpOnly/Secure/SameSite=Lax，有效7天。暂不支持短信/邮箱验证或密码找回，请使用独立密码。

后台持久保存账号、会话摘要、一次免费记录、正式订单、付费次数与每日额度、内容指纹、流水摘要。旧演示订单和余额保留原数据但不参与正式权益。AI问题、背景、牌面与有限历史会传给所配置的模型供应商；服务器以AES-GCM加密存储对话与重试结果，不保存其明文。会话资格1小时，但本版没有批量数据自动清理或账号删除界面。模型平台仍可能有独立数据规则与记录。更换模型密钥会使旧加密会话失效。

付费解读先在事务中预占次数，模型失败返还；成功后保存加密结果。并发操作不会重复生成或扣次；进程中断导致的预占会在2分钟租约过期后通过重新登录、刷新账号或再次解读恢复。实际模型调用仍受全站每日300次、每IP每小时20次和4并发上限约束，计数在内存，非供应商账单硬上限。

## 开发与发布

Node.js22+：`npm ci`、`npm run build`、`npm test`、`npx wrangler dev`。

GitHub main 通过 Cloudflare Workers Builds 部署；自有域名和既有SQLite Durable Object绑定保留。模型Key只放Cloudflare Secret；本机临时用gitignored的.dev.vars。不要提交真实配置、管理凭证或数据库。GUANXIN_ADMIN_KEY_HASH是公开的高熵随机凭证单向校验值，不是登录凭证。

`python tools/build_pages.py`生成旧入口跳转页，`python tools/verify_live.py`只读验证公开访问边界，不创建账号、不确认订单、不调用模型。worker/generated-library.js为构建产物，不提交。历史llm-backend是本机Python版，不是公网账号认证后台。

停站：GUANXIN_SITE_ENABLED=false并重新部署。仅暂停模型：GUANXIN_AI_ENABLED=false，已有付费次数保留。删除仓库不能保证独立Cloudflare服务停止，勿随意删除保存账号的Durable Object。

## 后台账号登录

管理页支持独立用户名和密码，密码仅以随机盐PBKDF2哈希保存于私有Durable Object存储，不写入公开配置。后台会话独立于普通用户，HttpOnly/Secure/SameSite=Lax，2小时有效，最多5个会话；支持退出。初始化接口只接受原负责人恢复凭证且只能初始化一次；原随机凭证保留作私密恢复用途，不再要求日常粘贴。管理员登录失败有独立限流，普通注册账号不能进入后台。

## 负责人前后台通用账号

管理员可在主站或后台使用同一用户名密码登录，共用受保护的管理员会话。主站显示“负责人测试”和后台入口。负责人全部牌阵、本地解读、真实AI及追问无需充值，不扣免费/次卡/月卡额度、不产生订单；模型本身限流、停用与并发保护仍适用。权限由服务端验证管理员会话，不能由用户名、客户端admin标志或普通账号获得。退出或两小时会话过期后失效，普通用户规则不变。
