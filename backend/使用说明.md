# 观心 · 本地发码后台

Python 3.11及以上，无第三方运行依赖。执行 `python server.py` 或双击启动脚本。

- 买家统一激活入口：http://127.0.0.1:8771/
- 管理首页 / 生成码：http://127.0.0.1:8772/
- 发码记录：http://127.0.0.1:8772/records
- 激活记录：http://127.0.0.1:8772/activations

管理员口令位于data/admin-password.txt，仅本地保存，不上传仓库。

## 定价和有效期

9.9元，首次激活起30天（30×24小时），期间不限次数。所有买家共用入口，各用各的码，绑定一个浏览器。
未激活时不计时。重置产生新码、作废旧码与旧登录，保留首次激活和原到期时间，不延长有效期。过期后换码仍然过期；新付费周期需新建订单记录。

## 发码与记录

核对店铺收款后填写订单标记并勾选确认，再生成随机6位数字码。保留前导零，已发出的历史码不会被复用。此后台不自动验证支付。
发码记录显示当前码、交付内容、订单首次发码时间、当前码发码时间、首次激活、到期状态；支持复制、重置及停用。换码历史保留旧码和作废时间，并标注已作废。
新版本为了允许重新复制，原码和历史码存于本地数据库，仅通过管理员接口读取。旧版本只存摘要的码无法恢复显示，仍可按原码激活，或在管理页重置后查看新码。

## 激活和设备记录

激活记录显示首次激活、到期时间、粗略系统和浏览器类型、最近活跃、访问次数、阅读解读次数以及其他浏览器激活被拒次数。
设备名称来源于User-Agent，可被伪造，不能识别唯一硬件或判断不同用户。访问含刷新；解读计数来自去重客户端事件，可能漏报，不适合作财务数据。不上传用户填写的问题和解读内容，不存IP历史或设备指纹。

## 本地数据和升级

data目录含口令、数据库和备份，勿发给买家或上传GitHub。升级保留现有订单和码，新有效期以首次激活时间计算；未激活记录首次激活后开始30天。当前修改前已备份数据库。
凭证为HttpOnly Cookie。换浏览器、清理数据、无痕模式或Cookie丢失需重置。已加载页面在可见状态下每60秒校验，停用或过期后下一次校验退出；不能防止已获授权用户保存网页内容。

## 部署范围

当前只监听本机，不开放外网，不接支付。GitHub Pages仍是公开免费体验版，工作流不发布backend目录；GitHub保存代码不等于运行后台。
未来远程提供服务需配置HTTPS、Secure Cookie、后台凭证管理、订单交付及备份。不要静态发布本目录。6位码空间有限，需保留尝试限速并在公网部署前加强风控。
