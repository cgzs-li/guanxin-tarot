# 观心 · 激活码本地测试版

运行需要 Python 3.11 或更新版本，无第三方依赖。双击「启动本地测试.cmd」，或执行 `python server.py`。

- 买家入口：http://127.0.0.1:8770/
- 发码管理：http://127.0.0.1:8770/admin
- 首次运行自动生成管理员口令，见 `data/admin-password.txt`。不要发给买家，不要上传 GitHub。

## 演练流程

1. 使用管理员口令登录管理页。
2. 填 TEST-001，勾选本地演练收款确认，生成码。正式运营必须先在店铺确认实际收款。
3. 复制交付内容，在常用浏览器访问买家入口，输入码。
4. 再用另一个浏览器或无痕窗口输入同一码，应提示已经绑定。
5. 在管理页重置并换码，旧码和旧登录失效；将新码交付买家。
6. 停用记录后，该浏览器再次请求受保护页面或图片将被拒绝。

## 范围与限制

本版仅监听本机127.0.0.1，链接不能发给真实买家远程使用；尚未上线，也不接收或验证支付。GitHub免费体验版未更改。

绑定的是HttpOnly Cookie登录凭证，不是实名身份或硬件。Cookie按浏览器策略保存，最长设置一年；清理数据、无痕、换浏览器或Cookie过期需要卖家重置。没有按天或次数扣减授权。

授权校验在服务器端，应用HTML、JS、牌义和牌图均在登录后才提供。随机激活码有128位随机熵，数据库仅存码和浏览器凭证的SHA-256摘要；管理员口令文件仅用于本地演练。管理页不显示旧码，可以重置生成新码。

它不能防止用户拷贝已经下载的网页、复制浏览器凭证或传播既有公开版。当前规则解读运行在用户浏览器内，停用不能让已经加载的页面即时消失。要销售更强保护的版本，需要上线后台，并将关键解读请求移入服务端；不能宣传绝对防分享。

## 正式部署前

选择服务器与域名，启用HTTPS与Secure Cookie，迁移管理员凭证到安全配置、配置备份与订单核验/平台发货，明确换绑和售后政策，再完成公网与手机真机测试。不要把本目录作为静态网站发布，否则private目录可能被直接下载。

data目录含许可数据库与管理员秘密，只用于服务端，禁止交付给买家或推送仓库。原有公开网站不是本版付费入口。报价9.9元仅为你确认的测试定价，不表示款项已收到。

## 使用统计

管理页可按订单查看激活时间、最近活跃、页面访问次数与阅读解读次数，并手动刷新。
页面访问次数包括刷新。解读事件使用随机事件编号去重；断网可能漏报，不是不可伪造的财务数据。
可见页面每60秒发送一次活跃请求；重新切回页面也会校验。停用后下次请求返回未授权并回到登录页。它不是持续在线监控，不采集姓名、IP历史、浏览器指纹、用户问题或解读正文。
许可数据库属于本地运营数据，data目录不上传GitHub。备份时复制data目录并妥善保管。

## GitHub代码位置

仓库中backend目录保存本地后台源代码，GitHub Actions仅发布原有静态体验页，不部署后台。data目录、密码和订单记录被Git忽略。代码上传不表示买家已能连接本机，当前不开放外网。
